ISub transaction codes
Needed to turn SIMs off or on, choose the data, calls and SMS SIM, and block mobile data per SIM. They differ between ROM builds, and a wrong code calls a different system method. The module reads them from your ROM automatically. If that fails, take them from your build's framework.jar (ISub$Stub) and confirm them below. Network types work without them.
