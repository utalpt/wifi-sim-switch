# Changelog

## v6.7
First public release.

- Two SIM profiles, On WiFi and Off WiFi: turn each SIM on or off, or limit its network types; pick the SIM for data, calls and SMS
- Mobile data blocked per SIM, so only the data SIM can use data, including during WiFi/mobile transitions
- WebUI with live SIM status, profile editor, log and 6 themes
- ISub transaction codes read from the running ROM automatically, with a fallback list and manual confirmation
- Live status on the module card in the KernelSU manager
- Action button pauses and resumes the module
- Magisk installer files (untested on Magisk; the WebUI needs WebUI X or MMRL there)
